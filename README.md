## How to Run

### 1. Run Backend
```bash
cd backend
npm start
```
*Backend server runs on `http://localhost:7777`.*

### 2. Run Frontend
```bash
cd frontend
npm run dev
```
*Frontend opens at `http://localhost:5173`.*
